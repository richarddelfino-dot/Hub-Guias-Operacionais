# Hub-Guias-Operacionais
O HUB Operacional Market4u é um portal web Single-File centralizado e responsivo (Mobile-First) para unificar e distribuir guias, manuais e treinamentos da rede. Integrado via iframe, oferece busca em tempo real, modo tela cheia e arquitetura plug-and-play para inclusão ilimitada de materiais com zero retrabalho.
